## Зачем это нужно

Если у вас Blender с русской локализацией, встроенный поиск в меню
**«Добавить модификатор»** ищет только по переведённым названиям. Знаете, что такое
`Bevel`, `Solidify` или `Shrinkwrap`, но не помните, как это звучит по‑русски? Приходится
листать список вручную.

**Modifier Search RU/EN** добавляет свой поиск, который понимает **оба языка сразу** —
вводите `bevel` или `фаска`, результат будет одинаковым.

## ✨ Возможности

- 🔎 **Поиск на двух языках одновременно** — каждый пункт списка подписан как
  `English | Русский`, находится по любому варианту ввода.
- ⚡ **Список модификаторов не хардкодится** — берётся напрямую из RNA текущей версии
  Blender, поэтому всегда актуален и не может «отстать» от новых релизов.
- 🌍 **Работает для любого языка интерфейса**, не только русского — перевод получается
  через встроенный переводчик Blender (`bpy.app.translations`), а не через ручной словарь.
- 🧩 **Три точки входа**, чтобы было удобно в любом контексте:
  - кнопка над списком модификаторов на вкладке свойств;
  - пункт вверху системного меню «Добавить модификатор»;
  - горячая клавиша `Ctrl + F3`.
- 🛡️ **Устойчив к граничным случаям**: корректно фильтрует модификаторы Grease Pencil
  от обычных, исключает служебные внутренние типы, которые не предназначены для
  ручного добавления, и не падает с трейсбеком при несовместимых сочетаниях —
  вместо этого показывает понятное сообщение.

## 📦 Установка

Это **официальное расширение Blender** (формат Extensions, Blender 4.2+), а не
классический аддон — устанавливается из `.zip`, распаковывать вручную не нужно.

1. Скачайте `modifier_search_ru_en-1.0.0.zip` из [Releases](../../releases/modifier_search_ru_en-1.0.0.zip)
   или из корня репозитория.
2. `Edit → Preferences → Get Extensions` → значок `⌄` в правом верхнем углу →
   **Install from Disk…**
3. Выберите скачанный `.zip`.
4. Готово — аддон включится автоматически.

> Если у вас Blender младше 4.2 (классическая система аддонов), тот же `.zip`
> подойдёт и для `Preferences → Add-ons → Install`.


## 🚀 Использование

| Способ | Где искать |
|---|---|
| Кнопка в панели | Properties → Modifiers → **«Поиск модификатора EN/RU»** |
| Пункт меню | «Добавить модификатор» → **«Поиск EN/RU…»** (вверху списка) |
| Горячая клавиша | `Ctrl + F3` в 3D Viewport (Object Mode) |

Начните вводить название — `bevel`, `фаска`, `subsurf`, `подразделение` — и выберите
нужный пункт. Модификатор добавится к активному объекту сразу же.



## ⚠️ Известные ограничения

- Пока не поддерживаются новые модификаторы на Geometry Nodes из библиотеки
  Essentials (Array (новый), Scatter on Surface, Instance on Elements и др.) —
  они добавляются через отдельный оператор `modifier_add_node_group`, а не через
  классический `modifier_add`. Планируется в следующих версиях.
- Фильтрация по типу объекта сейчас разделяет только Grease Pencil / остальные —
  для редких сочетаний (например, специфичные модификаторы кривых/решёток на меше)
  возможна ошибка добавления. Она обрабатывается аккуратно (без трейсбека), но сам
  пункт из списка пока не скрывается.
